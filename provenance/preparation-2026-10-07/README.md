# AI-08 Context dependent use of internal signals

Does context merely change the strength of a reusable internal signal, or change the computation that consumes it? The first pilot crosses fixed source signals with recipient wording and mention order in the qualified GPT-2 Medium task family from AI-01.

**Status on 7 October 2026: preparation only.** Prompt candidates, intervention plans and lightweight checks are available. No tokenization qualification, model loading, activation extraction or inference has occurred. The new inference adapter and mechanistic tests require implementation and numerical qualification before experiments.
