# AI-08 additional pathways and interactions completed

The fresh confirmation supports two additional attention heads beyond the five known query heads. In the full-strength third-name condition, the expanded Q/A/M intervention removed **70.92%** of the order effect and recreated **63.42%**. On those same inputs, Q alone removed 47.08% and recreated 34.75%. The selected MLP contribution was smaller and less consistent, and joint restoration was below the sum of isolated effects.

The stronger joint criterion failed, so the result is an independently confirmed **partial causal explanation**. The bounded study is complete, with no additional experiment running or scheduled.
