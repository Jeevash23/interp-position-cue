# AI-08 tests of additional pathways and interactions

This separately authorized follow-up starts after the completed position-routing-v2 study. It asks whether additional attention heads, feed-forward outputs, or their interactions with five known queries account for a substantial part of the remaining fixed-source order effect. Earlier evidence remains sealed. This is a targeted model-specific explanation attempt, not a claim to discover a new universal circuit principle.

## Fixed scope and selection

Retain the checkpoint, twelve source heads, source context, repeated-subject insertion position, five known query heads and float32 deterministic adapter from V2. Source clean-minus-corrupt vectors are extracted once and cached. Within each name/role/corruption unit, normalize each projected head vector to the canonical order-0 source norm. Apply strengths 0.5 and 1.0. Sharing particular source/recipient identities is retained here because V2 already tested identity transfer; V3 targets additional computation.

Screen exactly 32 old development cases: all four old recipient name triples, two old contexts, both roles and orders, F10 wording and third-name corruption. Test each of the 267 noncanonical attention heads in blocks 7–23 and each of the 17 MLP blocks 7–23, at the final prompt position, while the five known queries are held at that recipient's corrupted baseline. Block 7 is the first block that can transmit a source edit in block 6 from the repeated-subject position to the final position. The candidate set and 574 screen conditions are fixed before new model measurements.

Rank each candidate by its mean additional removal of the matched-minus-opposite order contrast, conditional on the known queries being fixed. Select exactly the top two attention heads and top one MLP, with ties broken by candidate id. Report their signs and consistency over development names, including weak or negative candidates; do not substitute candidates after downstream results. Screen support requires positive mean removal and a positive effect in at least three of four name units for each selected candidate. The factorial experiment is completed even if this descriptive screen flag fails, so failure is not an excuse for a second selection round.

The selected attention-head group A contains two heads; M contains one MLP; Q contains the five known queries. Matched-layer sham heads exclude the selected and known query heads. The sham MLP is one other block among 7–23. Generate controls with seed 2026100824 after deterministic selection, using no control outcome to choose them. Freeze the selected sites and controls before the development factorial panel.

## Factorial interventions and robustness

For each source order and strength, test all eight subsets of Q/A/M clamped to their own unedited recipient states under the full source correction. Separately, start with no source correction and transplant each of the seven nonempty subsets from the full corrected recipient. The Q variables are final-position queries, A variables are pre-projection attention-head outputs, and M variables are MLP outputs. Explicit replacements affect only the final position; later computation responds normally. These are interventions on computational paths, not uniquely identified natural causal shares.

Add clamps and transplants for Q plus the sham attention group, and for Q plus the sham MLP. Add complete final-position attention/MLP replacement in blocks 7–23 in both directions: baseline replacement should abolish the source effect and corrected-state replacement should reproduce it. These broad replacements are numerical boundary controls, not a compact proposed mechanism. Include independent zero writes. There are 86 saved factorial conditions per recipient.

Development uses 256 cases: four old name units, four old contexts, two old wordings, both roles/orders, and two corruptions. The first corruption substitutes a third name at the repeated-subject position, as before. The second substitutes the intended indirect-object name there, creating a sentence with the opposite intended answer. Use the corresponding corruption in each source extraction. The experimental target remains the original clean answer; additionally measure whether the model solves the reversed clean task in the second corruption.

Confirmation uses eight fresh name triples, eight fresh location/object pairs, two fresh wording templates, both roles/orders and both corruptions: 1,024 cases. Names are deterministically selected by tokenization alone, without replacement based on model behavior. All 24 names, all context pairs and all confirmation prompt strings must be disjoint from prior AI-08 inputs. Both wordings are crossed with every name/context unit. Their names need not be absent from pretraining or other portfolio studies. The 32 screening cases are contained in development, so screening and development counts are not counts of independent samples.

Freeze the protocol, inputs, adapter, runner, selection rule, analysis and statistical tests before qualification. After development, freeze the selected mechanism's observed numeric predictions and all audit/replay procedures before measuring confirmation. No selection, fitting, tolerance changes or retries to seek a favorable confirmation result are allowed. Numerical failures must be preserved, diagnosed, and requalified before further scientific measurement.

## Measurements and inference

The primary response is the raw intended-answer-minus-subject logit margin. For each corruption and dose, D is its matched-minus-opposite source-order contrast. Retain every case; do not filter by baseline correctness. Use ratios of aggregate contrasts rather than individual case ratios. Independent axes are name units and lexical contexts; roles, orders, wordings, corruptions and interventions remain paired inside these units. Use 20,000 crossed resamples with seed 2026100823.

There are four primary quantities in each of four robustness strata: joint necessity (D minus QAM-clamped contrast)/D; joint sufficiency (QAM-transplant contrast)/D; extra necessity (Q-clamped minus QAM-clamped contrast)/D; and extra sufficiency (QAM transplant minus Q-only transplant)/D. Give all 16 quantities 99.6875% percentile intervals, using Bonferroni alpha 0.05/16. Denominators must exceed 0.25, and no more than 1% of bootstrap denominators may be at or below 0.25. Count invalid draws; do not drop them.

The strong explanation criterion requires, in every stratum, joint necessity and sufficiency point estimates at least 0.75 with simultaneous lower bounds above 0.5, and both extra effects at least 0.15 with simultaneous lower bounds above zero. The source order contrast must be positive in at least 75% of name units and contexts. For each additional group, require its Q-plus-group necessity and sufficiency to exceed the corresponding Q-plus-sham by at least 0.05D, with descriptive 95% lower bounds above zero. These specificity checks are additional gates; their intervals do not support an independently multiplicity-controlled family of component claims.

Require clean recipient competence of at least 85% top-1 in every wording/order cell, mean clean/corrupt margin separation at least 0.5 and positive separation in at least 75% of cases. Apply the same competence thresholds to each source corruption/order cell. Require the repeat-IO corrupted sentences to choose their reversed correct answer at least 85% of the time overall. Numerical qualification must pass. Failure means the strong explanation is not established; do not expand the selected mechanism or change thresholds. Complete the declared controls, audit, report, and close this study with scoped results.

Report all factorial contrasts, pairwise interactions and the joint transplant's departure from the sum of its three isolated effects. Positive transplant interaction means the interventions cooperate in this assay; negative interaction means less than the sum. Clamp interactions have a different estimand and need not agree. Neither establishes a unique causal decomposition or absence of untested pathways. Interaction intervals are descriptive 95%, not additional primary discoveries. Save development expectations before confirmation and compare them transparently even when the strong criterion fails.

## Numerical verification and evidence retention

Every recipient probe uses a constant batch of eight identical prompts, with padding counted as inference work. Qualification compares the wrapped model to the original adapter, independent repeats, no-effect replacements, and complete END-path abolition/restoration on eight development cases including both corruptions. Require logit/state maximum absolute error no greater than 0.0005 and no changed full-vocabulary top answer for equivalent conditions. Check exact writes at each target.

Save raw float32 logits for both target names and the final residual vector for every condition. Compute full-vocabulary top-1, normalizers, entropy and KL before discarding the other logits. Preserve full vocabulary logits and complete Q/Z/MLP intervention traces on a fixed audit sample: first and last name units crossed with first and last contexts, role 0 and order 0, both wordings and corruptions. This yields four screen cases and 16 cases in each factorial bank. All five natural states per recipient retain full logits and Q/Z/MLP caches. This storage policy is fixed before measurements; it does not select favorable examples. Primary margin auditing covers every condition; independent full-vocabulary and intervention-trace auditing covers that declared subset.

Recompute all primary effects independently from the two saved raw logits, independently reconstruct crossed bootstrap weights, verify input separation/semantic alignment and all source reuse hashes, reproduce analysis into a fresh directory, and replay all fixed audit cases plus source extractions at their original batch shapes. Full-trace cases allow independent verification of replacements. Preserve upstream manifests and verify the earlier studies intact before and after completion. No model training, network model downloads, publication or scheduled continuation is authorized by this protocol.

Changing patching metrics and corruption methods can change conclusions; this motivates explicitly crossing corruption methods here.
