# AI-08 causal follow-up — completed

The order effect transfers between different names. Queries in five fixed, literature-selected attention heads make a causal contribution: clamping them removes **46.2%** of the confirmation order contrast, and transplanting them alone recreates **31.3%**. The predeclared stronger joint criterion failed, so the conclusion is a **partial causal explanation**.

The completed follow-up contains 640 recipient cases, 96 source pairs and 28,800 primary condition records, including 512 fresh confirmation cases. Qualification, independent evidence/input audits, saved-analysis replay and fixed-sample model replay passed. All 64 replayed recipient panels and all 96 re-extracted sources were bitwise identical.
