# Fixed signal response prediction

Recorded after numerical/behavioral qualification and before any development intervention panel or holdout model outcome. Qualification passed: all source cells 100% clean top-1, recipient cells 90.625–100%, positive clean/corrupt separation in all examples. Largest measured repeat/batch/projection coordinate discrepancy was 0.000244141; no top-1 prediction changed.

Retain the prepared full 13-condition panel in each recipient: two sources at -0.5, +0.5 and +1; untouched corrupted; explicit zero write; recipient self correction; four per-head-norm-matched random directions reused across contexts. Development source vectors and natural baselines are reused from qualification, preserving their hashes; holdout baselines and source caches are computed only after model/analysis selection is frozen. Full logits, source arrays and raw residual states after blocks 13, 18 and 23 are retained. Define response as patched state minus the explicit zero-write state in the same recipient.

The primary response layer is the final block, 23. Blocks 13 and 18 are prespecified secondary depth diagnostics. For each name triple, lexical context, role, source variant and strength, the F10/order-0 response is a measured reference x. Predict the other three cells y. This uses a paid-for measured holdout reference, included in the condition count; it is not zero-intervention prediction.

Fit a scalar gain separately for each target cell, source variant and strength by least squares through zero. Compare y_hat=alpha*x against y_hat=alpha*x + (x P) B_cell P-transpose. P is an uncentered orthonormal projection fitted only on training responses/references; B_cell is a ridge map shared across strengths and source variants for a target cell. Retain original-space residual errors including all discarded projection energy. Candidate ranks are 1,2,4,8, ridge fractions .001,.01,.1,1,10. Penalize B with ridge fraction times mean diagonal of its feature Gram matrix. This extra map can also change amplitude; separately score its error component perpendicular to x so amplitude flexibility cannot masquerade as a directional improvement.

Select rank/ridge by sixteen crossed development folds. Each fold holds out one name group and one lexical-context group at their intersection and excludes both complete groups from training. Refit projection, gains and map within every fold. Choose minimum total original-space validation squared error, breaking ties by smaller rank then stronger regularization. Refit on all development observations once. Freeze selected model arrays before observing holdout outcomes. Do not tune on holdout. Also compute the per-example best scalar projection (an explicitly nonpredictive oracle) to quantify directional discrepancy after removing arbitrary amplitude differences.

Primary loss is total squared prediction error divided by total squared target-response norm. Record per-crossed-cell contributions and errors decomposed parallel/perpendicular to each reference. Inference resamples name groups and lexical-context groups independently, retaining roles, sources, strengths and wording cells together. Use 20,000 crossed bootstrap draws, seed 2026100809. Four groups per axis in this pilot give limited precision; intervals describe this finite test and are not precise population estimates.

For direction summaries flag a reference or target norm <=0.25 as unavailable, a conservative floor exceeding twenty times the observed coordinate-error upper bound multiplied by sqrt(1024). Keep all cases in loss, coverage and behavior reporting; never remove held-out clean failures. Report full results and a separately described subset where source, reference and target clean predictions are correct.

Continue to mechanistic localization only if all apply: clean source/recipient gates remain met; predictive improvement has positive 95% crossed interval and is at least .05 absolute normalized loss and 10% relative loss; the improvement includes at least .02 normalized perpendicular-error reduction; at least three of four holdout name groups and three of four context groups show positive improvement; at least 95% of primary pairs have usable direction estimates; positive-strength fixed-source edits improve the intended margin on average and repair more than random controls. Negative strengths, alternate source order, self correction, norms, entropy and KL disruption are reported, not relabeled as causal routing evidence.

If the directional gate fails, finish the controlled inference and audit with a scoped negative or inconclusive prediction result; do not start an unrestricted head sweep. If it passes, choose candidate mediators using development observations only, then freeze a causal test and genuinely fresh AI-08 name/context groups. A fixed-signal directional effect alone is not a routing claim. A separate symbolic fallback would require an explicitly recorded new design, never silent substitution.
